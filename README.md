# Getting Started

First, you need to install make. Make can be installed by the link [here](https://gnuwin32.sourceforge.net/packages/make.htm).  

Clone outshell:
```shell
git clone https://someVeryCoolProgrammer/outshell.git
```

Switch to outshell's directory:
```shell
cd outshell
```

Compile outshell:
```shell
make all
```

Run outshell:  
```shell
.\bin\main.exe
```

PLEASE MAKE SURE **NOT** TO RUN:
```shell
make all | .\bin\main.exe
```
It causes the program to enter an infinite while loop.
